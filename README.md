# Shatter OSS

**Shatter** is an addon for Blender that allows the creation of segments (parts of levels) for the mobile game *Smash Hit*.

## Usage and help

Please see [the wiki](https://codeberg.org/knot126/Shatter-OSS/wiki) for information about how to use the addon, as well as some technical information about Smash Hit and the mesh baker.

You can find help on various communities centered around Smash Hit modding, like the Smash Hit Lab or Shards.
